# Lectures

Store complete topic lectures here, grouped by module.

Example:
```
lectures/
  module-09/
    topic-09-08-sop-reporting-and-dashboard.md
    topic-09-09-continuous-improvement.md
```

Use lowercase kebab-case slugs. Keep topic numbers stable. A revised lecture updates the same canonical file; do not create duplicate versions unless explicitly requested.

Each file should begin with YAML front matter:
```yaml
---
module: 9
topic: "9.8"
title: "S&OP Reporting and Dashboard"
language: "Taglish"
status: "complete"
---
```
