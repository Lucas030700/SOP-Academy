# Mobile App

Planned implementation: offline-first Progressive Web App (PWA).

Requirements:
- Installable on iPhone and Android where supported by the browser.
- Responsive mobile-first interface.
- Local lecture cache and local learning progress.
- Search, bookmarks, notes, glossary, formula library, and quizzes.
- GitHub repository is the master content source.
- Offline reading works after initial download.
- No user account required for local reading.
- Do not embed GitHub personal access tokens in client-side app code.

Synchronization must use a secure server-side or user-authorized publishing mechanism. A public repository's read-only content can be fetched without exposing write credentials.
